**Пример запроса:**
"Напиши код для подключения LCD 1602 к Arduino"

**Пример ответа:**
```cpp
#include <LiquidCrystal.h>

// RS→A0, E→A1, D4-D7→A2-A5
// Почему A0-A5? Они ближе к шинам питания, провода короче
LiquidCrystal lcd(A0, A1, A2, A3, A4, A5);

void setup() {
  lcd.begin(16, 2);  // Инициализация: 16 символов, 2 строки
  lcd.print("Hello!");  // Вывод текста в позицию (0,0)
}

void loop() {
  // Пусто, текст выведен один раз
}
```

**Как это работает:**
Библиотека LiquidCrystal дёргает пины RS, E, D4-D7 в нужной последовательности. RS=1 означает "данные", RS=0 означает "команда". E — импульс записи. D4-D7 — 4-битный режим (экономия пинов).

**3 способа сломать:**
1. Отключить RW от GND → дисплей в режиме чтения, текст не обновляется
2. Поменять RS и E местами → библиотека путает команды и данные, кракозябры
3. Убрать резистор 220Ω с BLA → подсветка сгорит через несколько секунд

**На ESP-IDF:**
Вместо библиотеки — прямая работа с пинами через `gpio_set_level()`. Нужно самому дёргать RS, E, шлить байты по 4 бита. Сложнее, но понимаешь, как работает.
