# 🚗 Smart Runout Scanner v1.0

## 📋 Назначение
**Автономный индикатор биения колёсных дисков с лазерным датчиком**

Устройство для быстрой диагностики биения дисков на шиномонтажном станке. Заменяет визуальный контроль и линейку — показывает отклонения в реальном времени.

### Почему ESP32 вместо Arduino
| Критерий | Arduino Nano | ESP32 | Выгода |
|----------|-------------|-------|--------|
| **Напряжение** | 5В логика | 3.3В логика | Прямое подключение VL53L1X без level shifter |
| **ADC** | 10 бит | 12 бит | Точнее измерения |
| **Память** | 2KB RAM | 520KB RAM | Буферизация данных, фильтрация |
| **Связь** | Нет | Wi-Fi/Bluetooth | Передача данных на телефон, логирование |
| **Цена** | ~300₽ | ~500₽ | +200₽ за мощь в 100 раз |

## 🏗 Архитектура устройства

### Компоненты
| Компонент | Функция | Подключение |
|-----------|---------|-------------|
| **VL53L1X** | Лазерный дальномер (измеряет расстояние до края диска) | I²C (SDA/SCL) к 3.3В |
| **ESP32** | Обработка данных, вычисление отклонений, Wi-Fi | Основной контроллер |
| **RGB-светодиод** | Показывает статус (зелёный/жёлтый/красный) | GPIO D9/D10/D11 через 220Ω |
| **Зуммер** | Звуковые сигналы при отклонениях | GPIO D3 через транзистор 2N2222 |
| **Кнопка CALIB** | Запуск калибровки | GPIO D2 с pull-up 10кΩ |
| **AMS1117-3.3** | Стабилизатор питания для датчика | 12В → 3.3В |

### Электрическая схема (критически важно!)

**⚠️ VL53L1X подключать ТОЛЬКО к 3.3В! Подача 5В приведёт к выходу из строя!**

```
Питание 12В
    │
    ├───[Диод 1N4007]───[AMS1117-3.3]─── VL53L1X VCC
    │                        │
    │                   [10мкФ]        [10мкФ]
    │                        │              │
    └────────────────────────┴──────────────┴─── GND

ESP32 подключения:
┌─────────────┬──────────┬─────────────────────┐
│ Компонент   │ Пин ESP32│ Примечание          │
├─────────────┼──────────┼─────────────────────┤
│ VL53L1X SDA │ GPIO 21  │ I²C, pull-up 4.7кΩ  │
│ VL53L1X SCL │ GPIO 22  │ I²C, pull-up 4.7кΩ  │
│ RGB Red     │ GPIO 9   │ Через 220Ω          │
│ RGB Green   │ GPIO 10  │ Через 220Ω          │
│ RGB Blue    │ GPIO 11  │ Через 220Ω          │
│ Зуммер      │ GPIO 3   │ Через транзистор    │
│ Кнопка CALIB│ GPIO 2   │ Pull-up 10кΩ        │
└─────────────┴──────────┴─────────────────────┘
```

## 💻 Программное обеспечение

### Режимы работы
```
Sleep → [Кнопка/Вращение] → Calibration → Scan → [Навигация] → Sleep
```

| Режим | Описание | Индикация |
|-------|----------|-----------|
| **Sleep** | Ожидание, минимальное потребление | Синий (тускло) |
| **Calibration** | Калибровка по ровному диску | Голубой → Зелёный |
| **Scan** | Измерение в реальном времени | Зелёный/Жёлтый/Красный |
| **Navigate** | Поиск точки максимума для правки | Мигание по направлению |

### Алгоритм калибровки
1. Снять **N=50 замеров** за 1 оборот диска
2. Вычислить среднее: `Baseline = Σdi / N`
3. Вычислить стандартное отклонение: `σ = √(Σ(di - Baseline)² / N)`
4. Установить пороги:
   - Жёлтый: `2σ`
   - Красный: `4σ`

### Алгоритм сканирования
```
Текущее отклонение: Δd = d_current - Baseline
Амплитуда биения: A = max(Δd) - min(Δd)

Статус:
🟢 Зелёный: A < 2σ    (диск ровный)
🟡 Жёлтый:  2σ ≤ A < 4σ (небольшое биение)
🔴 Красный: A ≥ 4σ    (критичное биение!)
```

### Режим навигации (правка)
**Назначение:** Помочь найти точку максимального выпирания для правки гидравлическим прессом

- При приближении к максимуму: **частота писка увеличивается**
- В точке максимума: **непрерывный тон**
- RGB: **мигание по направлению к максимуму**

### Преимущества ESP32 (v2.0)
- [ ] **Wi-Fi передача данных** → график на телефоне в реальном времени
- [ ] **Логирование** → сохранение истории правок
- [ ] **Bluetooth** → быстрое подключение без ввода пароля
- [ ] **OTA обновления** → прошивка без подключения кабеля
- [ ] **Deep Sleep** → работа от батареи неделями

## 📖 Инструкция пользователя

### Включение
1. Переключить тумблер в **ON**
2. Индикатор мигнёт синим и погаснет (режим ожидания)

### Калибровка
1. Установить **ровный диск** на станок
2. Прикрепить устройство магнитом к **неподвижной части**
3. Датчик должен смотреть на край диска (5-15 см)
4. Нажать кнопку **CALIB**
5. Индикатор: **Голубой → Зелёный** + короткий писк
6. Готово!

### Диагностика
1. Начать вращать диск рукой (1 оборот за 2-3 сек)
2. Устройство автоматически включится (жёлтый на 1 сек)
3. Смотреть на индикатор:
   - 🟢 Зелёный (редкий бип) → диск ровный
   - 🟡 Жёлтый (прерывистый писк) → небольшое биение
   - 🔴 Красный (частый писк) → критичное биение!

### Правка (режим навигации)
1. После диагностики медленно вращать диск
2. **Слушать звук:** чем чаще писк, тем ближе к точке максимума
3. В точке самого громкого и частого писка → **остановиться**
4. Это место максимального выпирания
5. Надавить гидравлическим прессом
6. Снова проверить вращением

### Выключение
- **Авто:** через 30 секунд бездействия
- **Вручную:** тумблер в OFF

### Индикация батареи
| Индикатор | Заряд |
|-----------|-------|
| 🟢 Зелёный | > 50% |
| 🟡 Жёлтый | 20-50% |
| 🔴 Красный (мигает) | < 20% — заряди! |

## ⚠️ Риски и решения

| Риск | Вероятность | Решение |
|------|-------------|---------|
| **Ложное срабатывание на грузики** | 🔴 Высокая | Софт-фильтр: игнорировать пики < 0.3 сек. Визуальный осмотр перед стартом |
| **Вибрация от цеха** | 🟡 Средняя | Усреднение: брать среднее из 5-10 замеров. Амортизирующая прокладка под магнит |
| **Загрязнение линзы** | 🔴 Высокая | Утопить датчик в корпус. Регулярная протирка. Индикация ошибки (фиолетовый) |
| **Разрядка в процессе** | 🟢 Низкая | Индикатор батареи (< 15% мигает красным). Работа от USB (powerbank) параллельно |
| **Слепые зоны** | 🟡 Средняя | Выносной датчик на гибком держателе. Разные точки крепления |
| **Ослепление солнцем** | 🟢 Низкая | Защитный козырёк. В закрытом боксе не актуально |

## ✅ Чек-лист перед сборкой

### Электрика
- [ ] Все земли соединены в одну точку (GND)
- [ ] AMS1117 IN подключён после диода 1N4007
- [ ] AMS1117 OUT имеет конденсатор 10мкФ на землю
- [ ] **VL53L1X VCC → 3.3В, а НЕ 5В!** (критично!)
- [ ] У каждого светодиода свой резистор 220Ω
- [ ] Зуммер подключён через транзистор (2N2222 или MOSFET)
- [ ] Диод защиты стрелкой ОТ источника (катод к нагрузке)
- [ ] Полярность конденсаторов соблюдена (+ к плюсу, полоска на корпусе)

### Механика
- [ ] Нет оголённых проводов, которые могут замкнуть
- [ ] Корпус закрыт, крышка не давит на компоненты
- [ ] Магниты приклеены правильно (одинаковая полярность)
- [ ] Кнопка и тумблер подписаны
- [ ] Окно для лазера прозрачное, не царапанное

### Программирование
- [ ] Код загружен в ESP32
- [ ] Библиотека `VL53L1X` установлена
- [ ] Wi-Fi credentials настроены (если используется)
- [ ] Тестовый запуск: все режимы работают
- [ ] Мультиметр под рукой для проверки
