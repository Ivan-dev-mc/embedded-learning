# 💾 Auto Backup Trigger (Физический триггер бэкапов)

## 📋 Назначение
Физическая кнопка для запуска комплексного, автоматизированного резервного копирования рабочих данных, конфигов и Git-репозиториев.
Убирает страх потери данных и рутину ручных операций.

## 🎯 Боль
- Забываю сделать `git push` перед выключением или переходом к другой задаче.
- Лень бэкапить конфиги (VPN, Obsidian, IDE, терминал) — они хранятся локально и могут потеряться при переустановке.
- Ручные бэкапы занимают время, их легко пропустить.
- Страх «сломал систему — потерял наработки».

## 💡 Решение
Одна кнопка на столе. При нажатии ESP32 шлёт сигнал на ПК.
Python-скрипт на ПК выполняет **идемпотентный** пайплайн:
1. `git add . && git commit -m "auto-backup $(date)"` (только если есть изменения)
2. `git push` (в приватный репо)
3. Архивация конфигов: Obsidian, PlatformIO, VPN, SSH
4. Синхронизация на внешний диск/облако/NAS
5. Очистка старых локальных бэкапов (>7 дней)
Обратная связь: LED (🟢 Успех / 🟡 В процессе / 🔴  Ошибка) + звук.

## 🏗 Архитектура устройства

### Компоненты
| Компонент | Функция | Подключение |
|-----------|---------|-------------|
| ESP32 WROOM | Wi-Fi клиент, логика триггера, индикация | USB 5V (питание) |
| Тактовая кнопка | Запуск пайплайна | GPIO 4, internal pull-up |
| RGB LED (WS2812B или дискретный) | Статус бэкапа | GPIO 5 |
| Пьезо-пищалка | Звуковое подтверждение | GPIO 18 |

### Схема взаимодействия
```
[Кнопка] ──► [ESP32] ──(HTTP POST /backup)──► [ПК: Python Script]
                                                  │
                                                  ├── Git (commit/push)
                                                  ├── Tar/Rsync (конфиги)
                                                  ├── Cloud/Local Sync
                                                  └── Cleanup (старые архивы)
```
️ **Важно:** Скрипт должен быть **идемпотентным**. Повторный запуск не должен дублировать коммиты или ломать архивы.

##  Программное обеспечение

### Стек
- **ESP32:** Arduino Core / ESP-IDF, `HTTPClient`, `WiFi`, `FastLED`
- **ПК:** Python 3, `gitpython`, `subprocess`, `requests`, `shutil`, `tarfile`
- **ОС:** Linux (cron/systemd timer для проверки) или Windows (Task Scheduler)

### Пример кода ESP32 (Триггер)
```cpp
#include <WiFi.h>
#include <HTTPClient.h>

const char* ssid = "YOUR_WIFI";
const char* password = "YOUR_PASS";
const char* serverUrl = "http://192.168.1.100:5000/backup";

void setup() {
  pinMode(4, INPUT_PULLUP);
  pinMode(5, OUTPUT);
  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) delay(500);
}

void loop() {
  if (digitalRead(4) == LOW) {
    digitalWrite(5, HIGH); // 🟡 В процессе
    
    HTTPClient http;
    http.begin(serverUrl);
    int code = http.POST("");
    http.end();
    
    if (code == 200) {
      digitalWrite(5, LOW); // 🟢 Успех (RGB выкл или зелёный)
      tone(18, 1500, 100);  // Короткий писк
    } else {
      digitalWrite(5, HIGH); // 🔴 Ошибка (RGB красный)
      tone(18, 300, 300);    // Длинный писк
    }
    delay(1000); // Защита от спама
  }
}
```

### Пример кода ПК (Python-пайплайн)
```python
from flask import Flask, jsonify
import subprocess, os, datetime, shutil

app = Flask(__name__)
BACKUP_DIR = "/home/user/backups"
PROJECTS_DIR = "/home/user/projects"
CONFIGS = [
    "/home/user/.ssh",
    "/home/user/.obsidian",
    "/home/user/.platformio"
]

def run(cmd):
    return subprocess.run(cmd, shell=True, capture_output=True, text=True)

@app.route('/backup', methods=['POST'])
def trigger_backup():
    try:
        ts = datetime.datetime.now().strftime("%Y%m%d_%H%M")
        
        # 1. Git (только если есть изменения)
        run("git add .")
        status = run("git status --porcelain")
        if status.stdout.strip():
            run(f'git commit -m "auto-backup {ts}"')
            run("git push origin main")
            
        # 2. Архивация конфигов
        os.makedirs(BACKUP_DIR, exist_ok=True)
        tar_path = os.path.join(BACKUP_DIR, f"configs_{ts}.tar.gz")
        run(f"tar -czf {tar_path} {' '.join(CONFIGS)}")
        
        # 3. Очистка старых (>7 дней)
        run(f"find {BACKUP_DIR} -name 'configs_*.tar.gz' -mtime +7 -delete")
        
        return jsonify({"status": "ok"}), 200
    except Exception as e:
        return jsonify({"status": "error", "msg": str(e)}), 500

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5000)
```

## 🐛 Отладка и диагностика
| Инструмент | Назначение |
|------------|------------|
| `Serial Monitor` | Лог Wi-Fi, статус HTTP-запросов, отладка кнопки |
| `curl -X POST http://IP:5000/backup` | Тест пайплайна без кнопки |
| `git log --oneline` | Проверка, что коммиты не дублируются |
| `ls -lah ~/backups` | Контроль размера и дат архивов |
| Консоль Python | Вывод ошибок `subprocess`, прав доступа, путей |

## ⚠️ Риски и решения
| Риск | Вероятность | Решение |
|------|-------------|---------|
| Скрипт запускается без изменений в Git | 🟡 Средняя | Проверка `git status --porcelain` перед коммитом |
| Обрыв сети во время `git push` | 🔴 Высокая | Настройка `git config --global http.postBuffer` + retry-логика в скрипте |
| Бэкап занимает слишком много места | 🟡 Средняя | Ротация архивов: хранить только последние 7 дней, сжатие `tar.gz` |
| Ложные срабатывания | 🟢 Низкая | Программный таймаут 1с, опционально: двойное нажатие для активации |
| Права доступа (sudo/root) | 🔴 Высокая | Запускать скрипт от имени пользователя, избегать `sudo` в автоматизации |

## 💡 Инсайты

> [!tip] Про идемпотентность #insight
> «Автоматизация должна быть безопасной при повторном запуске. Если скрипт бэкапа ломается при двойном нажатии — это не инструмент, это бомба замедленного действия».

> [!example] Почему Git + Архив, а не просто копирование? #insight
> «Git хранит историю изменений кода и метаданные. Архив (tar.gz) сохраняет состояние конфигов, которые не version-controlled. Два слоя защиты: один для кода, один для окружения».

> [!success] Про физический триггер #insight
> «Кнопка снижает когнитивную нагрузку: не нужно помнить команды, не нужно открывать терминал. Нажал — система сама решила, что делать, и подтвердила результат. Это инженерная эргономика».
