# ⏱ ESP32 Watch: Кастомные часы на запястье

## 📋 Назначение
Не «умные часы масс-маркет». Не «замена телефону».
**Твой личный интерфейс на запястье**, который показывает только то, что нужно тебе.

>[!tip] Философия
«Не 10 уведомлений в секунду. Только статус, только алерт, только по делу».

## 🎯 Проблемы, которые решает
| Боль                                             | Решение                                                                   |
| ------------------------------------------------ | ------------------------------------------------------------------------- |
| ❌ «Масс-маркет часы: много функций, мало моих»   | ✅ Только кастомные виджеты: время, статус задачи, алерты                  |
| ❌ «В шиномонтаже телефон неудобно доставать»     | ✅ Статус на запястье: «Заказ готов», «Пинг пропал», «Пора на перерыв»     |
| ❌ «Хочу контролировать инфраструктуру «на ходу»» | ✅ Алерты от Pocketing Engineer / Пи400 → вибрация + текст                 |
| ❌ «Хочу полигон для отработки UI/датчиков»       | ✅ Песочница: тестирование кода, который потом переносишь в другие проекты |

## 🏗 Архитектура

### Аппаратная часть
| Компонент | Варианты | Зачем | Примечание |
|-----------|----------|-------|------------|
| **Мозги** | ESP32-PICO-D4 / ESP32-S3-MINI-1 | Минимальный размер, 240 MHz, WiFi/BLE | S3 — больше памяти, но дороже |
| **Экран** | OLED 1.28" круглый (GC9A01) / TFT 1.54" (ST7789) | Вывод времени, виджетов, алертов | Круглый — стиль, прямоугольный — больше места |
| **Сенсоры** | MPU6050 (акселерометр+гироскоп) | Шаги, жесты, авто-поворот, тап-детекция | Опционально, можно без |
| **Ввод** | 2 кнопки + энкодер (вращающаяся кнопка) | Навигация без тача (надёжнее в шинке) | Энкодер — для скролла меню |
| **Питание** | LiPo 300-500 mAh + TP4056 / USB-C | 1-3 дня работы в зависимости от режима | Глубокий сон между запросами |
| **Доп.** | Buzzer (вибрация), RTC (резерв) | Алерты, точное время без сети | RTC — DS3231 или встроенный в ESP32 |

### Программная архитектура
```
┌─────────────────────────┐
│      State Machine      │ ← Всегда в одном режиме
├─────────────────────────┤
│  • WATCHFACE            │ ← Основной циферблат
│  • WIDGETS              │ ← Переключение: статус, алерты, таймер
│  • SETTINGS             │ ← Настройка времени, виджетов, яркости
│  • SLEEP                │ ← Deep Sleep ~10 µA
├─────────────────────────┤
│   FreeRTOS (планировщик)│ ← Ядро 0: сеть, Ядро 1: UI
├─────────────────────────┤
│   Модули (отдельные файлы):
│   • display_ui.cpp      │
│   • input_handler.cpp   │
│   • wifi_mgr.cpp        │
│   • ble_notifier.cpp    │
│   • widget_manager.cpp  │
│   • config_storage.cpp  │
└─────────────────────────┘
```

**Ключевые принципы:**
- **Минимализм интерфейса**: 3-4 уровня меню, крупные шрифты, иконки
- **Экономия батареи**: WiFi/BLE только по запросу → потом сон
- **Кастомизация через конфиг**: виджеты, цвета, расписание — не в коде, а в данных
- **Интеграция с экосистемой**: приём алертов от Pocket Engineer / Пи400

## 🎛 Функционал (виджеты и режимы)

### 🔹 Базовые (обязательные)
| Виджет | Что показывает | Польза |
|--------|---------------|--------|
| **Время** | Часы:минуты + дата + день недели | Основное назначение |
| **Статус-бар** | «Сервер: ✅», «Задача: Балансировка ×4», «Батарея: 78%» | Контроль важного без телефона |
| **Алерты** | Вибрация + текст: «Пинг пропал», «Заказ готов» | Реагируешь на событие, не проверяешь постоянно |

### 🔹 Интеграционные (связь с экосистемой)
| Виджет | Источник | Польза |
|--------|----------|--------|
| **Статус сканера** | BLE от Pocket Engineer | «Сканер: готов», «Ошибка: калибровка» — на запястье |
| **Уведомления с ПК** | BLE от Пи400 | «Бэкап завершён», «Компиляция упала» — без отвлечения |
| **Макро-кнопка** | Отправка команды на Пи400 | Долгое нажатие → «Запустить бэкап» / «Включить свет» |

### 🔹 Кастомные (только для тебя)
| Виджет | Реализация | Почему это твоё |
|--------|-----------|----------------|
| **Режим шинки** | Счётчик заказов, таймер смены | Учёт без бумаги, без телефона |
| **Крипто-тикер** | Запрос цены раз в 5 мин через WiFi | Контроль без залипания в биржу |
| **Цитата/мотивация** | Утром: случайная строка из твоего файла | Настрой без интернета |
| **Таймер задач** | «Через 20 мин — проверить компрессор» → вибрация | Не забыть рутину в запаре |

### 🔹 Опциональные (если будет ресурс)
| Фича | Что нужно | Польза |
|------|-----------|--------|
| **Шагомер** | MPU6050 + алгоритм | Базовый контроль активности |
| **Пульт (BLE/ИК)** | Управление светом/проектором | Одна кнопка на запястье = действие |
| **Погода/температура** | Запрос с открытого API | Планирование без телефона |

## ⚠️ Ограничения (будь готов)
| Ожидание | Реальность | Как жить с этим |
|----------|-----------|----------------|
| «Будет как Apple Watch» | ❌ Экран 1.3", 240×240, не тач, а кнопки | Это инструмент, не гаджет. Интерфейс — минималистичный |
| «Батарея на неделю» | ❌ 1-3 дня (WiFi жрёт), 5 дней (только BLE + сон) | Глубокий сон между запросами, зарядка раз в 2-3 дня |
| «Сердце, кислород, GPS» | ❌ ESP32 не тянет точные биометрические датчики без костылей | Оставь это телефону. Часы — для статуса и алертов |
| «Сложный интерфейс» | ❌ Мало памяти, маленький экран | Меню: 3-4 уровня, крупные шрифты, иконки |

### Память и оптимизация
| Ресурс | Бюджет | Стратегия |
|--------|--------|-----------|
| RAM | ~200 KB свободно | Буферы переиспользуются, строки в PROGMEM |
| Flash | ~4 MB | Прошивка ~1 MB, конфиги/виджеты ~3 MB |
| CPU | 2 ядра × 240 MHz | Ядро 0: сеть, Ядро 1: UI (FreeRTOS) |
| Питание | Deep Sleep ~10 µA | WiFi/BLE только по запросу, потом сон |

## 💡 Инсайты
> [!tip] Про минимализм
> «Не "всё, что можно". А "только то, что нужно". Каждый виджет — ответ на вопрос: "Зачем мне это на запястье?"»

> [!example] Про интеграцию
> «Часы не живут отдельно. Они — часть экосистемы: получают статус от карманного хаба, отправляют макросы на сервер».

> [!success] Про портфолио
> «Работодатель видит не "часы на ESP32". Он видит: "Человек спроектировал носимое устройство с кастомным UI, BLE-интеграцией и оптимизацией питания". Это уровень».
