# 🎯 PC Focus Controller (Физический триггер автоматизации)

##  Назначение
Физическая кнопка для запуска сложных сценариев подготовки рабочего места на ПК.
Убирает когнитивную нагрузку на рутину: вместо 5-10 минут настройки окружения — одно нажатие.

## 🎯 Боль
- Перед учёбой/кодингом тратится время на: закрытие лишнего, запуск IDE, включение музыки, настройку таймера.
- Сила воли уходит на подготовку, а не на саму работу.
- Хочется тактильного «ритуала» перехода в режим потока.
- Софт-макросы забываются или лень настраивать каждый раз.

## 💡 Решение
Большая тактильная кнопка на столе. При нажатии ESP32 шлёт HTTP-запрос на ПК.
Python-скрипт на ПК принимает сигнал и выполняет цепочку действий:
1. Закрывает браузер/мессенджеры
2. Открывает VS Code + Obsidian + Терминал
3. Запускает Lo-Fi музыку (Spotify/YouTube)
4. Включает режим «Не беспокоить» в ОС
5. Запускает Pomodoro-таймер (25 мин работа / 5 мин отдых)
Обратная связь: RGB LED + звук подтверждают запуск/ошибку.

## 🏗 Архитектура устройства

### Компоненты
| Компонент | Функция | Подключение |
|-----------|---------|-------------|
| ESP32 WROOM | Wi-Fi клиент, логика кнопки, индикация | USB 5V (питание) |
| Тактовая кнопка 30мм | Триггер сценария | GPIO 4, internal pull-up |
| RGB LED (WS2812B или дискретный) | Статус:  Готов / 🟡 Запуск / 🔴 Ошибка | GPIO 5 (или 3 GPIO) |
| Пьезо-пищалка | Звуковое подтверждение | GPIO 18 |

### Схема взаимодействия
```
[Кнопка] ──► [ESP32] ──(HTTP POST /focus)──► [ПК: Python Server]
                                              │
                                              ├── PyAutoGUI (закрытие/открытие окон)
                                              ├── subprocess (запуск приложений)
                                              ├── win10toast/plyer (уведомления)
                                              ── Pomodoro logic (таймер)
```
⚠️ **Важно:** ESP32 работает только как триггер. Вся логика автоматизации живёт на ПК. Это делает устройство дешёвым, надёжным и легко обновляемым.

## 💻 Программное обеспечение

### Стек
- **ESP32:** Arduino Core / ESP-IDF, `HTTPClient`, `WiFi`, `FastLED` (опционально)
- **ПК:** Python 3, `Flask`/`FastAPI` (лёгкий сервер), `pyautogui`, `subprocess`, `psutil`

### Пример кода ESP32 (Триггер)
```cpp
#include <WiFi.h>
#include <HTTPClient.h>

const char* ssid = "YOUR_WIFI";
const char* password = "YOUR_PASS";
const char* serverUrl = "http://192.168.1.100:5000/focus"; // IP ПК

void setup() {
  pinMode(4, INPUT_PULLUP); // Кнопка
  pinMode(5, OUTPUT);       // LED
  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) delay(500);
}

void loop() {
  if (digitalRead(4) == LOW) { // Нажатие
    digitalWrite(5, HIGH);     // LED: жёлтый (запуск)
    
    HTTPClient http;
    http.begin(serverUrl);
    int code = http.POST("");
    http.end();
    
    if (code == 200) {
      digitalWrite(5, LOW);    // LED: зелёный (успех)
      tone(18, 1000, 100);     // Писк подтверждения
    } else {
      digitalWrite(5, HIGH);   // LED: красный (ошибка)
      tone(18, 200, 300);      // Длинный писк ошибки
    }
    delay(500); // Антидребезг + защита от спама
  }
}
```

### Пример кода ПК (Сервер автоматизации)
```python
from flask import Flask
import subprocess, pyautogui, time

app = Flask(__name__)

@app.route('/focus', methods=['POST'])
def start_focus():
    try:
        # 1. Закрыть лишнее
        pyautogui.hotkey('alt', 'f4') 
        time.sleep(0.5)
        
        # 2. Запустить рабочее
        subprocess.Popen(['code', '.'])          # VS Code
        subprocess.Popen(['obsidian'])           # Obsidian
        subprocess.Popen(['powershell'])         # Терминал
        
        # 3. Музыка (Spotify Web Player или локальный плеер)
        # subprocess.Popen(['start', 'https://open.spotify.com/playlist/...'], shell=True)
        
        # 4. Уведомление
        print("✅ Focus Mode Activated")
        return "OK", 200
    except Exception as e:
        print(f"❌ Error: {e}")
        return "Error", 500

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5000)
```

## 🐛 Отладка и диагностика
| Инструмент | Назначение |
|------------|------------|
| `Serial Monitor` | Лог подключения Wi-Fi, статус HTTP-запросов, отладка кнопки |
| `curl http://IP:5000/focus -X POST` | Тест сервера на ПК без кнопки |
| Консоль Python | Вывод ошибок автоматизации (окно не найдено, путь неверный) |
| `ping IP_ESP32` | Проверка стабильности сети, задержек |

## ⚠️ Риски и решения
| Риск | Вероятность | Решение |
|------|-------------|---------|
| ПК спит / выключен | 🟡 Средняя | Добавить режим Wake-on-LAN (ESP32 шлёт Magic Packet) или локальный fallback (кнопка мигает, скрипт не вызывается) |
| Окна не закрываются / не открываются | 🔴 Высокая | `pyautogui` зависит от активного окна. Использовать `subprocess` с прямыми путями или `win32gui` для точного управления |
| Сеть обрывается во время нажатия | 🟡 Средняя | ESP32 ловит `HTTPClient` ошибку → мигает красным → пользователь понимает, что триггер не сработал |
| Ложные срабатывания (дребезг/случайное касание) | 🟢 Низкая | Программный таймаут 500мс после нажатия. Опционально: двойное нажатие для активации |
| Скрипт падает и висит в фоне |  Низкая | Обёртка `try/except` в Python, логирование в файл, автоматический рестарт через `systemd`/Task Scheduler |

## 💡 Инсайты

> [!tip] Про оркестровку vs HID #insight
> «Макроклавиатура шлёт символы. Контроллер фокуса управляет состоянием системы. Первое — замена пальцев. Второе — замена ритуала. Инженер автоматизирует не действия, а контекст».

> [!example] Почему Python на ПК, а не всё на ESP32? #insight
> «ESP32 не знает, какие окна открыты у тебя на Windows/Linux. Делегировать управление ОС скрипту на самом ПК — архитектурно верно. Микроконтроллер остаётся тупым триггером, что повышает надёжность и упрощает отладку».

> [!success] Про обратную связь #insight
> «Физическая кнопка без подтверждения статуса вызывает тревогу: "сработало или нет?". LED + звук закрывают петлю обратной связи. В инженерии интерфейс = доверие к системе».
