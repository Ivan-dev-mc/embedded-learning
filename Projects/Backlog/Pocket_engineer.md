# 🧰 Pocket Engineer: Универсальный карманный хаб

## 📋 Назначение

**Одно устройство в кармане, которое подстраивается под задачу.**

Не «ещё одна плата для обучения». Не «инструмент для одной функции».

**Личный цифровой интерфейс, который:**
- 🔧 Помогает отлаживать железо без ноутбука
- 📊 Автоматизирует учёт работ в шиномонтаже
- 🌐 Контролирует инфраструктуру (сервер, VPN, сеть)
- 🏠 Управляет бытовыми задачами (свет, таймеры, пульт)
- 🎮 Выполняет кастомные функции, нужные только тебе

> [!tip] Философия
> «Не 10 устройств под 10 задач. Одно устройство, которое становится тем, что нужно сейчас».

## 🏗 Архитектура

### Аппаратная часть

| Компонент | Зачем | Примечание |
|-----------|-------|------------|
| **ESP32 DevKit** | Мозги + вычисления + связь | 2 ядра, 240 MHz, 520 KB RAM, Wi‑Fi/BLE |
| **OLED 0.96" I²C** | Визуальный вывод | 128×64, 2 провода (SDA/SCL) |
| **Кнопки ×4 + энкодер** | Навигация, ввод | Дебаунс программный |
| **Адаптер-переходник** | Подключение к макетке/проводам | Для быстрой отладки |
| **Корпус (опционально)** | Защита, клипса на карман | 3D-печать или готовый бокс |

### Программная архитектура
```
┌─────────────────────────┐
│      State Machine      │ ← Устройство всегда в одном режиме
├─────────────────────────┤
│  • MENU                 │
│  • HOME_PROFILE         │ ← Умный пульт, таймер, среда
│  • WORK_PROFILE         │ ← Логгер, сканер сетей, датчики
│  • NETWORK_PROFILE      │ ← Монитор сервера, тестер портов
│  • PERSONAL_PROFILE     │ ← Часы, макро-пад, 2FA
│  • LAB_PROFILE          │ ← Песочница, генератор сигналов
│  • SLEEP                │ ← Deep Sleep ~10 µA
├─────────────────────────┤
│   FreeRTOS (планировщик)│ ← Распределение задач по ядрам
├─────────────────────────┤
│   Модули (отдельные файлы):
│   • wifi_manager.cpp    │
│   • i2c_scanner.cpp     │
│   • gpio_tester.cpp     │
│   • logger.cpp          │
│   • display_ui.cpp      │
│   • config_storage.cpp  │
└─────────────────────────┘
```

**Ключевые принципы:**
1.  **Модульность:** Каждый режим — отдельный файл. Включается только при входе.
2.  **Экономия ОЗУ:** Буферы переиспользуются, строки хранятся во флеше (`const`).
3.  **Сеть по требованию:** Wi‑Fi/BLE включаются только на время запроса → потом сон.
4.  **Конфиг на SD/Flash:** Настройки, макросы, профили — не в коде, а в данных.

## 🎛 Режимы (функционал)

### 🏠 Профиль: ДОМ
| Режим | Что делает | Польза |
|-------|-----------|--------|
| **Умный пульт** | ИК-сигналы для ТВ/кондиционера + сценарии | Одно устройство вместо 5 пультов |
| **Монитор среды** | Температура/влажность/давление + алерты | Контроль условий в гараже/мастерской |
| **Таймер задач** | Вибрация + экран: «Выключи компрессор» | Не забывать рутину в запаре |

### 🔧 Профиль: РАБОТА
| Режим | Что делает | Польза |
|-------|-----------|--------|
| **Логгер событий** | Кнопка → запись: «Балансировка ×4» → отправка в облако | Учёт работ без телефона/бумаги |
| **Сканер сетей** | Wi‑Fi: каналы, мощность; BLE: устройства вокруг | Настройка связи в цеху за 2 минуты |
| **Датчик-адаптер** | Подключил I²C-датчик → показал данные → отправил | Проверка железа без ноутбука |

### 🌐 Профиль: СЕТЬ
| Режим | Что делает | Польза |
|-------|-----------|--------|
| **Монитор инфраструктуры** | Пинг, статус портов, uptime VPN, алерты в ТГ | Контроль сервера без доступа к ПК |
| **Тестер подключения** | «Есть ли интернет?», «Доступен ли порт 22?» | Диагностика сети «на месте» |
| **2FA Генератор** | TOTP-коды оффлайн (как Google Authenticator) | Вход на серверы без телефона |

### 🎮 Профиль: ЛИЧНОЕ
| Режим | Что делает | Польза |
|-------|-----------|--------|
| **Кастомные часы** | Время + фаза луны + курс крипты + статус задачи | То, что нужно тебе, а не масс-маркету |
| **Макро-пад** | При подключении к ПК: кнопка = сложная команда | Автоматизация рутины на любом компьютере |
| **Шифратор заметок** | Запись паролей/ключей в зашифрованном виде на SD | Хранение чувствительных данных без облака |

### 🧪 Профиль: ЛАБ
| Режим | Что делает | Польза |
|-------|-----------|--------|
| **Serial Monitor** | Чтение/отправка по UART с другого МК | Отладка кода сканера без ноутбука |
| **GPIO Tester** | Подача 3.3В/0В, чтение состояния, PWM | Проверка кнопок/реле перед пайкой |
| **I²C Scanner** | Сканирование шины, показ адресов устройств | Быстрая диагностика «почему датчик не виден» |
| **Песочница кода** | Запуск небольших MicroPython-скриптов | Проверка идеи без ПК |
| **Сигнал-генератор** | ШИМ, частота, импульсы для тестов | Отладка схем «в поле» |

```ini
    bblanchon/ArduinoJson@^7.0.4
    knolleary/PubSubClient@^2.8
```

### Структура проекта
```
Pocket_Engineer/
├── src/
│   ├── main.cpp              # Точка входа, State Machine
│   ├── core/
│   │   ├── display.cpp       # UI, меню, отрисовка
│   │   ├── input.cpp         # Кнопки, энкодер, дебаунс
│   │   └── config.cpp        # Загрузка/сохранение настроек
│   ├── modes/
│   │   ├── home/             # Профиль ДОМ
│   │   ├── work/             # Профиль РАБОТА
│   │   ├── network/          # Профиль СЕТЬ
│   │   ├── personal/         # Профиль ЛИЧНОЕ
│   │   └── lab/              # Профиль ЛАБ
│   └── drivers/
│       ├── oled.cpp          # Драйвер дисплея
│       ├── wifi_mgr.cpp      # Менеджер Wi-Fi (вкл/выкл)
│       └── i2c_bus.cpp       # Обобщённый I²C-сканер
├── include/                  # Заголовки
├── data/                     # Конфиги, строки меню (флеш)
├── platformio.ini
└── README.md
```
### Память и оптимизация
| Ресурс | Бюджет | Стратегия |
|--------|--------|-----------|
| **RAM** | ~300 KB свободно | Буферы переиспользуются, строки в `PROGMEM` |
| **Flash** | ~4 MB | Прошивка ~1.5 MB, конфиги/данные ~2.5 MB |
| **CPU** | 2 ядра × 240 MHz | Ядро 0: сеть, Ядро 1: UI/датчики (FreeRTOS) |
| **Питание** | Deep Sleep ~10 µA | Wi‑Fi/BLE только по запросу, потом сон |
