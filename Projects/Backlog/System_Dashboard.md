# 📊 PC System Monitor (Cyberpunk Dashboard)

## 📋 Назначение
Внешний дисплей, показывающий системные метрики ПК в реальном времени.
Заменяет софтовые виджеты, добавляет «киберпанк-атмосферу» и даёт быстрый визуальный контроль нагрузки.

## 🎯 Боль
- Не видно, греется ли ноут при компиляции кода.
- Не понятно, почему лагает браузер (RAM или CPU?).
- Хочется видеть скорость сети (чтобы качать быстрее) и статус Spotify.
- Софт-виджеты отвлекают на рабочем столе.

## 💡 Решение
Python-скрипт на ПК собирает метрики через `psutil`, сериализует в JSON и отправляет по Serial (USB).
ESP32 принимает строку, парсит JSON и отрисовывает графики/текст на TFT-экране.
Обновление: 10 раз в секунду (10Hz).

##  Архитектура устройства

### Компоненты
| Компонент | Функция | Подключение |
|-----------|---------|-------------|
| ESP32 WROOM/S3 | Приём данных, отрисовка | USB-C (питание + данные Serial) |
| TFT ST7735 (1.8") или ILI9341 (2.4") | Вывод графики | SPI (MOSI, MISO, CLK, CS, DC, RST, BLK) |
| Кабель USB | Связь с ПК | USB-A to USB-C |

### Электрическая схема (SPI)
⚠️ **Важно:** SPI требует быстрых пинов. На ESP32 лучше использовать VSPI (GPIO 23, 19, 18, 5).

```
[ESP32] ──(MOSI 23)──► TFT
[ESP32] ──(MISO 19)──► TFT
[ESP32] ──(CLK 18)───► TFT
[ESP32] ──(CS 5)─────► TFT
[ESP32] ──(DC 4)─────► TFT (Data/Command)
[ESP32] ──(RST 22)───► TFT (Reset)
[ESP32] ──(BLK 21)───► TFT (Backlight)
[ESP32] ──(3.3V)─────► TFT VCC
[ESP32] ──(GND)──────► TFT GND

## 💻 Программное обеспечение

### Стек
- **ESP32:** `TFT_eSPI` (самая быстрая библиотека для Arduino/ESP-IDF), `ArduinoJson`.
- **ПК:** Python 3 + `psutil` (статистика) + `pyserial`.

### Протокол обмена (JSON)
Строка отправляется с ПК на ESP32 каждые 100мс.
```json
{"cpu": 45, "ram": 62, "net_down": 1.5, "net_up": 0.2, "fps": 60}
```

### Логика отрисовки (Оптимизация)
ТFT-экраны медленные. Перерисовывать всё 10 раз в секунду — вызовет мерцание.
**Правило:** Рисовать только то, что изменилось, или использовать двойную буферизацию.

**Алгоритм:**
```
1. Принять JSON.
2. Распарсить значения.
3. Если (CPU изменился > 1%) → перерисовать полоску CPU.
4. Если (RAM изменился > 1%) → перерисовать полоску RAM.
5. Текст (цифры) обновлять реже (1 раз в сек) или затирать чёрным перед новой записью.
```

### Пример кода ПК (Python)
```python
import psutil, serial, json, time

ser = serial.Serial('COM3', 115200) # Выбрать порт ESP32

while True:
    cpu = psutil.cpu_percent(interval=0.1)
    ram = psutil.virtual_memory().percent
    net = psutil.net_io_counters()
    
    # Считаем скорость за интервал
    down_mb = (net.bytes_recv / 1024 / 1024) # Упрощенно
    
    data = {
        "cpu": int(cpu),
        "ram": int(ram),
        "down": down_mb
    }
    
    ser.write(json.dumps(data).encode() + b'\n') # \n как разделитель
    time.sleep(0.1)
```

## ⚠️ Риски и решения
| Риск | Вероятность | Решение |
|------|-------------|---------|
| Экран мерцает | 🔴 Высокая | Не очищать весь экран (`tft.fillScreen`) каждый кадр. Рисовать поверх чёрным или обновлять только меняющиеся части |
| Данные не приходят | 🟡 Средняя | Проверь скорость (115200), драйверы USB, правильность пинов RX/TX |
| Медленная отрисовка | 🟡 Средняя | Увеличь `SPI_FREQUENCY` в `User_Setup.h` библиотеки (до 40-80 MHz) |
| ESP32 зависает при парсинге | 🟢 Низкая | Используй статический буфер в `ArduinoJson` (StaticJsonDocument<200>) |
