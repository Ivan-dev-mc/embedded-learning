# 🥧 Pi 400: Учебная станция + сервер + полигон

## 📋 Назначение

**Единая среда для обучения Embedded/IoT и практики с железом**

| Цель                     | Как реализуется                                              |
| ------------------------ | ------------------------------------------------------------ |
| 🐧 Учить Linux           | Нативная среда: терминал, systemd, сети, права, bash-скрипты |
| 🔌 Подключать устройства | 40-pin GPIO, USB-порты, UART/SPI/I²C напрямую                |
| 🔥 Учить пайку           | Камера + экран = видишь каждый контакт, записываешь процесс  |
| 📄 Читать даташиты       | Браузер + редактор + терминал в одном устройстве             |
| 📐 Читать распиновки     | Подключаешь МК → проверяешь сигналы логическим анализатором  |
| 🎮 «На крайняк поиграть» | Отдельная SD-карта с RetroPie/Recalbox для разгрузки мозга   |

> [!tip] Философия
> «Одно устройство — все задачи». Не переключаться между ноутбуком, сервером и «игровой консолью». Включил → выбрал профиль → работаешь.

---
### 🎒 Форм-фактор: мобильный стационар
- [ ] Корпус: сумка/пенал с отсеками (Pi400 + кабели + SD-карты + повербанк)
- [ ] Питание: универсальное (повербанк 5V/3A ИЛИ сетевой адаптер)
- [ ] Дисплей: любой с HDMI (ТВ, монитор, портативный экран, ноут как дисплей)
- [ ] Периферия: мышь — в карман, камера — по необходимости

*Цель: «Включил в любом месте — получил свою среду»* 
## 🏗 Архитектура использования

### Профили работы (разные SD-карты)

| Карта | Образ | Назначение |
|-------|-------|------------|
| **🔧 Learn** | Raspberry Pi OS Lite + PlatformIO | Основная учёба: Linux, код, прошивка МК |
| **🌐 Server** | Raspberry Pi OS + Docker | MQTT-брокер, БД, Grafana, VPN-шлюз |
| **🎮 Play** | RetroPie / Recalbox | Игры, отдых, тестирование железа «на расслабоне» |
| **🧪 Lab** | Кастомный образ с инструментами | Эксперименты, тесты, «сломал — перепрошил» |

**Преимущество:** Сломал систему в эксперименте → вставил другую карту → продолжаешь работать.

## 🎮 «На крайняк поиграть» — это не баг, это фича

> [!example] Почему это важно
> «Учиться 24/7 — путь к выгоранию. Возможность переключиться на игру без смены устройства = меньше трения, больше устойчивости».

**Как использовать:**
- Устал от кода → перезагрузился с **Play**-карты → 30 минут ретро-игр
- Мозг «остыл» → вернулся к **Learn**-карте → продолжишь с ясной головой

**Это не прокрастинация. Это управление энергией.**
