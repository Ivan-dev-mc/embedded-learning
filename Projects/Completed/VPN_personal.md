# 🛡️ Персональный VPN: отказоустойчивый доступ

## 📋 Проблема и контекст
- **Задача:** Стабильный, безопасный доступ к ресурсам из любой точки мира
- **Пользователи:** 2 человека (я + Сильвина)
- **Требования:** 
  - ✅ Простота подключения («одна кнопка» для не-технаря)
  - ✅ Устойчивость к блокировкам (DPI, провайдеры)
  - ✅ Быстрое восстановление при сбое
  - ✅ Минимальная стоимость владения

## 🏗 Архитектура

### Основной стек
┌─────────────────┐
│   Клиент (App)  │
└────────┬────────┘
         │ TLS + VLESS+Reality
         ▼
┌─────────────────┐
│  Xray-core      │
│  • Main inbound │

│  • flow: xtls-rprx-vision │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│   Хостер (VPS)  │

`

### Протоколы и отказоустойчивость
| Компонент | Назначение | Статус |
|-----------|------------|--------|
| **VLESS+Reality** | Основной транспорт, маскировка под легитимный сайт, обход DPI | ✅ Активен |
| **flow: xtls-rprx-vision** | Оптимизация трафика, снижение детектируемости | ✅ Настроен |
| **Backup inbound** | Резервный вход с другими ключами/UUID для быстрого переключения | ✅ Готов |
| **WireGuard (удалён)** | Был как запасной вариант, удалён за ненадобностью | ❌ Убран |
| **Shadowsocks/Trojan** | Тестировались, удалены для минимизации поверхности атаки | ❌ Убраны |

### Инфраструктурные решения
- **Домен:** Арендован на год → абстракция от IP, возможность миграции без перенастройки клиентов
- **Бэкапы:** Ежедневная отправка 3 файлов через бота:
  1. `configs/` — актуальные конфиги Xray
  2. `database/` — база пользователей/ключей
  3. `validator.sh` — скрипт проверки целостности связки
- **Disaster Recovery:** Скрипт «развёртывание с нуля за 5 минут» на любом хостере
- **UX для пользователя:** Сильвина подключается в 1 клик (конфиг импортирован, приложение настроено)
