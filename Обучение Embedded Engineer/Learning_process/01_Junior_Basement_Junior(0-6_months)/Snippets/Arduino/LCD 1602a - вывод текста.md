### ✅ РАБОТАЕТ (правильное подключение)

**Пины:**
```
LCD 1602          Arduino UNO
─────────────────────────────────
1. GND     →      GND (чёрная шина)
2. VDD     →      5V (красная шина)
3. V0      →      Средний пин потенциометра
4. RS      →      A0 (или D2)
5. RW      →      GND (ОБЯЗАТЕЛЬНО!)
6. E       →      A1 (или D3)
7. D4     →      A2 (или D4)
8. D5     →      A3 (или D5)
9. D6     →      A4 (или D6)
10. D7     →      A5 (или D7)
11. BLA    →      5V через резистор 220Ω
12. BLK    →      GND
```

**Потенциометр (10кОм):**
```
Левый пин   → 5V
Средний пин → V0 (пин 3 LCD)
Правый пин  → GND
```

### ⚡ ЗАСТАВЛЯЕТ РАБОТАТЬ (минимальный код)

**PlatformIO (LiquidCrystalRus):**
```cpp
#include <LiquidCrystalRus.h>
LiquidCrystalRus lcd(A0, A1, A2, A3, A4, A5);

void setup() {
  lcd.begin(16, 2);
  lcd.print("Привет, мир!");
  lcd.setCursor(0, 1);
  lcd.print("LCD works!");
}

void loop() {}
```

**Arduino IDE (стандартная LiquidCrystal):**
```cpp
#include <LiquidCrystal.h>
LiquidCrystal lcd(A0, A1, A2, A3, A4, A5);

void setup() {
  lcd.begin(16, 2);
  lcd.print("Hello World!");
  lcd.setCursor(0, 1);
  lcd.print("LCD works!");
}

void loop() {}
```

### 💥 ЛОМАЕТ (примеры ошибок)

| Ошибка | Симптом | Почему |
|--------|---------|--------|
| **RW не на GND** | Квадратики есть, текст не меняется | Дисплей в режиме чтения |
| **Нет общей земли** | Подсветка горит, экран мёртвый | Нет цепи тока |
| **Не крутил потенциометр** | Синий экран, текста не видно | Контраст на минимуме |
| **BLA без резистора** | Подсветка сгорела (0.133V) | Слишком большой ток |
| **RS и E перепутаны** | Кракозябры или пустота | Библиотека путает команды |
| **Один из D4-D7 отключен** | Мусор на экране | Потеряна половина данных |
| **V0 на 5V вместо GND** | Текст исчезает | Контраст выкручен в минимум |
| **Питание VDD не подключено** | Только подсветка горит | Контроллер не запитан |

### 🔧 Быстрая диагностика

**Экран мёртвый:**
1. Проверь 5V и GND на шинах
2. RW → GND
3. Крути потенциометр от края до края
4. Пошевели каждый провод

**Подсветка не горит:**
- Проверь резистор 220Ω на BLA
- BLK → GND
- Мультиметром: BLA→BLK должно быть 1.8-3.3V

**Текст не виден:**
- Крути потенциометр!
- Посвети фонариком на экран

---

**Запомни:** 90% проблем — это забытая земля, RW не на GND или не настроен контраст.
