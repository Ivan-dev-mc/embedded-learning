# Blink LED

## Подключение

| Пин компонента | Пин МК |
|----------------|--------|
| LED (+)        | 13     |
| LED (-)        | GND    |

## Код

```cpp
#include <Arduino.h>

#define LED_PIN 13  // Встроенный LED на Arduino UNO

void setup() {
  pinMode(LED_PIN, OUTPUT);  // Настраиваем пин как выход
}

void loop() {
  digitalWrite(LED_PIN, HIGH);  // Подаём 5V (LED горит)
  delay(1000);                   // Ждём 1 секунду
  digitalWrite(LED_PIN, LOW);   // Подаём 0V (LED гаснет)
  delay(1000);                   // Ждём 1 секунду
}
```
## Как это работает

`digitalWrite(LED_PIN, HIGH)` подаёт 5V на пин 13. Встроенный резистор уже есть на плате, поэтому внешний не нужен.

**Что происходит на уровне железа:**

- `pinMode(LED_PIN, OUTPUT)` записывает бит в регистр DDRB (Data Direction Register B)
- `digitalWrite(LED_PIN, HIGH)` записывает бит в регистр PORTB
- Пин 13 на Arduino UNO = PB5 (Port B, bit 5)

## Что ломает

1. **Убрать `delay()`** → LED мигает слишком быстро (микросекунды), глаз не видит, кажется что горит постоянно
2. **Поменять `HIGH` на `LOW`** → логика инвертирована, LED горит "наоборот" (включён когда должен быть выключен)
3. **Забыть `pinMode(LED_PIN, OUTPUT)`** → пин в состоянии INPUT по умолчанию, LED не загорится или будет тусклым

## Адаптация под ESP32

На ESP32 встроенный LED на **GPIO2** (не 13!). Логика та же, но:

- Напряжение 3.3V вместо 5V
- Вместо `digitalWrite()` → `gpio_set_level(GPIO_NUM_2, 1)`
- Нужно настроить пин через `gpio_config()` перед использованием
