##  Ключевые принципы

1. **Теория только для текущей задачи** — не учи "всё про C", учи то, что нужно для проекта.
2. **Нейронка — помощник, не автор** — объясняй каждую строку кода.
3. **Ломай и чини** — создавай проблемы, записывай решения.
4. **Git с первого дня** — коммить после каждого рабочего сниппета.
5. **Dev-log = проблемы и решения** — не послужной список.
6. **Английский через документацию** — читай ESP-IDF docs с переводчиком, выписывай термины.
7. **Измеряй ток** — после каждого проекта замеряй потребление.
8. **Тесты на ПК** — выноси логику в отдельные файлы, тестируй без железа.
