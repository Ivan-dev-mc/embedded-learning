# 🧠 AI Integration & Hardware Strategy

## 1. Теория: Что такое ИИ-чипы?
Специализированные процессоры для ускорения матричных вычислений (ядро работы нейросетей).

| Тип | Назначение | Пример |
|-----|------------|--------|
| **CPU** | Универсальные задачи (последовательно) | ESP32, STM32 |
| **GPU** | Параллельные вычисления (графика + ИИ) | NVIDIA (PC), Mali |
| **TPU/NPU** | Только матричные вычисления (быстро) | Google TPU, Apple NPU |
| **FPGA** | Перепрограммируемая логика | Xilinx |

> [!note] Для Embedded
> ESP32 **не имеет** NPU. Он использует векторные инструкции (SIMD) для ускорения TinyML. Если нужно реальное ИИ на борту — нужен спец. чип.

---

## 2. Аппаратные альтернативы (Железо для ИИ)

Если ESP32 не тянет задачи компьютерного зрения или тяжелых моделей:

| Плата | Что внутри | Цена | Применение |
|-------|------------|------|------------|
| **Kendryte K210** | RISC-V + NPU (0.8 TOPS) | ~600₽ | Распознавание лиц/объектов, дёшево |
| **OpenMV Cam H7** | STM32 + Камера | ~4000₽ | Прототип CV без пайки, Python |
| **RP2040 + Accel** | MCU + внешний NPU (Hailo) | ~3000₽+ | Сложные модели, гибкость |
| **ESP32-S3** | Векторные инструкции (SIMD) | ~600₽ | TinyML, базовые классификаторы |

## 3. Концепция: ИИ-Отладчик (JARVIS для цеха)
Интеграция ИИ в `[[Pocket_Engineer]]` для диагностики устройств без ноутбука.

### Архитектура уровней
1. **🟢 Экспертная система (Сейчас)**
   - База правил: `ЕСЛИ "NOT FOUND" → ТО "Проверь подтяжку"`.
   - Не требует обучения, работает мгновенно.
2. **🟡 TinyML (Через 3-6 мес)**
   - Распознавание паттернов сбоев (аномалии в логах).
   - Работает оффлайн на ESP32-S3/K210.
3. **🔴 Гибридный LLM (Через 6-12 мес)**
   - Pocket Engineer шлёт лог → `[[Pi400_workstation]]` (Ollama) → Ответ с диагнозом.
   - Требует сеть, но даёт глубокое понимание контекста.

## 4. Бэклог идей (Экосистема)

| Идея | Боль | Навык | Приоритет |
|------|------|-------|-----------|
| **Auto-Diagnose Mode** | Диагностика в цеху без ПК | Протоколы, парсинг | 🔴 Высокий |
| **Голосовые макросы** | Учёт руками в масле | Whisper, MQTT | 🟡 Средний |
| **Predictive Maintenance** | Чинить до поломки | TinyML, датасеты | 🟡 Средний |
| **Контекстные профили** | Ручное переключение | BLE/GPS, State Machine | 🟡 Средний |
| **Централизованный лог** | Разрозненные данные | SQLite, MQTT | 🟡 Средний |

---

## 5. Правила внедрения (Mindset)

- [ ] **Не распыляться.** Одна идея → один микро-шаг → релиз.
- [ ] **Начинать с простого.** Экспертная система полезнее недоученного TinyML.
- [ ] **Фиксировать в логе.** Что сломалось → Почему → Как починил.
- [ ] **Фокус на боли.** Если фича не экономит время/нервы — в бэклог.

> [!tip] Главный вывод
> ИИ — это не магия. Это инструмент, который закрывает конкретные задачи: диагностика, распознавание паттернов, голосовое управление.
> **Твой путь:** Правила → TinyML → Гибридный LLM.
